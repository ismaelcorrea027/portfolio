# VetCare

Protótipo conceitual em HTML, CSS e JavaScript. Abra `index.html` diretamente ou use um servidor HTTP estático na raiz do portfólio.

- Navegação por seções, menu mobile, detalhes de serviços e artigos.
- Agendamento demonstrativo com validação dos campos, seleção de serviço e confirmação local. Não envia nem armazena dados.
- Imagens do mockup original reutilizadas como fundos posicionados em CSS. O arquivo de origem permanece preservado em `imagens/behance/clinica-veterinaria.png`.
- As seções adicionais dão continuidade ao protótipo; o print de referência cobre a apresentação, serviços, sobre e especialidades.
- Sem dependências externas ou etapa de build.
