# Padrão para novos projetos e cases

Ao adicionar um projeto ou case ao portfólio:
- Adicionar um card na seção correspondente (intranets, sistemas etc.).
- Para imagens, abrir a prévia no modal existente.
- Para protótipos em código, usar link para o index do projeto com target="_blank", rel="noopener noreferrer" e classe no-lightbox.
- Incluir o logo e a identificação na seção de empresas somente para empresas reais atendidas; evitar duplicatas.
- Todos os projetos criados na seção Behance são fictícios/conceituais. Não adicionar suas marcas ou logos à seção de empresas atendidas.
- Gerar uma miniatura representativa e verificar os links e os arquivos locais.
- Preservar os arquivos de origem. Ao preparar publicação, incluir apenas os arquivos necessários ao protótipo; não incluir PSDs e backups por padrão.

## Layout dos projetos no estilo SharePoint Modern

- Os fundos das seções devem ocupar 100% da largura da página.
- O conteúdo de cada seção deve permanecer em um container centralizado, com largura máxima de 1120 px e margens laterais responsivas.
- Não expandir o conteúdo para toda a largura ao aplicar fundos de seção full width.
- Seguir este padrão em novos projetos SharePoint Modern, salvo orientação explícita diferente do usuário.

## Organização e publicação

- Manter os cards de empresas em ordem alfabética pelo nome, inclusive ao adicionar novas logos.
- Enviar alterações ao GitHub somente quando o usuário solicitar explicitamente a publicação.
