# Medicina esportiva — Dra. Marina Azevedo

Protótipo conceitual em HTML, CSS e JavaScript. Abra index.html diretamente ou use um servidor estático na raiz do portfólio. Nenhum build é necessário.

## Recursos
- Layout baseado no mockup original, preservado em assets/mockup-original.png.
- Navegação responsiva, detalhes de especialidades e conteúdos em modal, abas acessíveis e formulário demonstrativo com validação.
- Animações de entrada e hover com suporte a prefers-reduced-motion.
- Formulário sem envio, persistência ou agendamento real. Profissional e indicadores fictícios.
- Card na seção Behance abre em nova aba; nenhuma inclusão na seção de empresas atendidas.
