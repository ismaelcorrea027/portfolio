# Natália Rodrigues — Nutricionista

Versão independente da base personal-trainer, em HTML, CSS e JavaScript puro. Identidade baseada no layout imagens/behance/site-nutricionista.png: verde-oliva, creme, dourado e títulos serifados. Sem bibliotecas, build ou instalação; abrir index.html diretamente ou servir esta pasta.

Preserva carrossel de abertura, menu responsivo, animações de entrada, filtros, formatos de acompanhamento, carrossel de depoimentos e galeria ampliável com dialog nativo.

Natália Rodrigues é uma personagem fictícia. Fotos geradas por IA e depoimentos demonstrativos. Nenhum registro profissional, contato, resultado clínico ou agenda real é alegado. O formulário prepara uma mensagem para copiar ou baixar; não transmite nem armazena dados e não confirma agendamento. A newsletter também é demonstrativa.
